# 🤖 JarvisBot — ИИ-Ассистент в Telegram

Telegram-бот, созданный по образу искусственного интеллекта Джарвиса из вселенной Marvel. Бот умеет отправлять медиафайлы и общаться с пользователем, используя современные нейросети.

## 🚀 Возможности
- 🎼 Аудиомодуль: Воспроизведение встроенных треков (саундтрека Мстителей) по клику на кнопку.
- 🖼 База данных изображений: Отправка картинок и фотографий ассистента из локальных файлов.
- 🧠 Интеграция с ИИ: Полноценные ответы на любые вопросы пользователя через бесплатный модуль нейросетей g4f (модель GPT-4) с сохранением фирменного вежливого стиля общения Джарвиса ("Сэр").

## 🛠 Используемые технологии
- Язык программирования: Python 3
- Библиотеки:
  - pyTelegramBotAPI (`telebot`) — для взаимодействия с API Telegram.
  - g4f (GPT4Free) — для бесплатного доступа к языковым моделям ИИ.
  - wikipediaapi — для интеграции со справочными данными Википедии.

## 💻 Инструкция по запуску

1. Склонируйте репозиторий с кодом.
2. Установите все необходимые библиотеки:
     pip install pyTelegramBotAPI g4f wikipediaapi
   3. Убедитесь, что в одной папке со скриптом бота находятся файлы:
   - avengers.mp3 (для музыки)
   - Джарвис2.jpg (для фото)
4. Откройте код бота и вставьте ваш токен от [@BotFather](https://t.me) вместо 'YOUR_BOT_TOKEN':
     token = 'ТВОЙ_ТОКЕН_ЗДЕСЬ'
   5. Запустите скрипт через терминал или среду разработки:
     python main.py
